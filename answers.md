  №  Сцена                                  Що вивелося         Хто винен   Як уникнути                                                                  
 -:  -------------------------------------  ------------------  ----------  ---------------------------------------------------------------------------- 
  1  `let name; console.log(name);`         `undefined`         JavaScript  Одразу присвоїти змінній початкове значення.                                 
  2  `let name = null; console.log(name);`  `null`              Розробник   Якщо значення відоме, присвоїти його замість `null`.                         
  3  `greet();`                             `Hello, undefined`  JavaScript  Передавати аргумент або встановити значення за замовчуванням.                
  4  `return a + b;`                        `5`                 Ніхто       Код написаний правильно, нічого змінювати не потрібно.                       
  5  Забули `return`                        `undefined`         Розробник   Додати оператор `return result;`.                                            
  6  `return;`                              `undefined`         Розробник   Повернути потрібне значення замість порожнього `return`.                     
  7  `console.log(user.age);`               `undefined`         JavaScript  Переконатися, що властивість існує або перевірити її перед використанням.    
  8  `console.log(user.middleName);`        `null`              Розробник   Якщо значення має бути відсутнім свідомо — `null` використовувати правильно. 
  9  `console.log(arr[10]);`                `undefined`         JavaScript  Перевіряти, чи індекс не виходить за межі масиву.                            
 10  `console.log(user.address.street);`    `undefined`         JavaScript  Використовувати оператор `?.` або перевіряти існування властивості.
